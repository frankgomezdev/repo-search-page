# Github repositories search page

This repository provides a solution to the exercise on React Practice which is to build a Github Repositories search page, with sorting and pagination.
The results should be paginated; by default, show 10 repositories per page

Users should be able to:

- search repositories by name
- choose how many items to show per page
- choose what to sort by: best-match, stars, most-updated

Exercise: [https://reactpractice.dev/exercise/build-a-github-repositories-search-page-with-sorting-and-pagination/]
